# Отчёт по итерации 20 — отложенный замер изделия

## Реализовано

- длина и ширина для позиции в м² больше не обязательны при приёмке;
- длина для позиции в погонных метрах также может быть указана позднее;
- неизвестный размер отображается как «Ожидает замера»;
- предварительная стоимость неизмеренной позиции равна нулю;
- заказ можно принять до фактического замера;
- замер можно внести или скорректировать в карточке изделия;
- площадь и стоимость позиции пересчитываются автоматически;
- итоговая сумма заказа обновляется в той же транзакции;
- для расчёта используется цена, зафиксированная при добавлении позиции;
- выданные и отменённые изделия изменить нельзя;
- изделие без фактического замера нельзя выдать клиенту;
- квитанция явно сообщает, что позиция ожидает замера;
- изменение замера записывается в аудит.

## Рабочий сценарий

1. Приёмщик выбирает ковёр и оставляет длину и ширину пустыми.
2. Система добавляет позицию со статусом «Ожидает замера» и стоимостью 0 ₽.
3. Заказ оформляется и передаётся в производство.
4. Сотрудник раскрывает детали позиции и вводит фактическую длину и ширину.
5. Система рассчитывает площадь и обновляет итоговую сумму заказа.

## Проверка

- PostgreSQL integration-тест создания позиции без размеров;
- integration-тест замера после принятия заказа;
- компонентный тест формы последующего замера;
- тест отметки «Ожидает замера» в квитанции;
- lint, форматирование и production-сборка.
