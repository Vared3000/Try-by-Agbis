# Отчёт по итерации 8 — производство

## Реализовано

- поиск изделия по непрозрачному `scanCode`;
- tenant и branch isolation при сканировании и переходах;
- data-driven маршрут из `ProductionRouteStage`;
- строгая последовательность этапов без перескоков;
- старт и завершение этапа с row locking изделия;
- назначение активного сотрудника только из того же филиала;
- назначение рабочего места той же организации;
- отдельное разрешение `production.quality_control` для возврата на доработку;
- возврат с контроля качества на предыдущий этап и повторное прохождение;
- перевод изделия в `ready` после последнего этапа;
- автоматический статус заказа `partially_ready` или `ready`;
- история этапов и история статуса заказа;
- audit log и transactional outbox для производственных событий.

## Проверки

PostgreSQL integration-тест выполняет:

1. сканирование кода;
2. старт первого этапа;
3. назначение исполнителя;
4. завершение обработки;
5. контроль качества;
6. возврат на доработку;
7. повторную обработку и контроль;
8. упаковку;
9. проверку готовности изделия и заказа.
