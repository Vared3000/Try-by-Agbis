# Отчёт по итерации 12 — фотографии и выдача заказа

## Реализовано

- загрузка фотографий отдельно для каждой принятой вещи;
- защищённый просмотр фотографий непосредственно в карточке заказа;
- удаление ошибочной фотографии, пока заказ остаётся черновиком;
- запрет удаления фотографий после приёмки заказа;
- отображение срока готовности, комментария, оплаты и задолженности;
- выбор одной или нескольких готовых позиций для частичной выдачи;
- подтверждение выдачи всех выбранных позиций;
- обязательное основание для выдачи заказа с задолженностью;
- автоматическое обновление карточки и списка заказов после выдачи.

## Проверка

- API возвращает фотографии вместе с позициями заказа без внутренних ключей
  хранилища;
- интеграционный тест подтверждает неизменяемость фотографии принятого заказа;
- полный сценарий проходит от создания номенклатуры и заказа до трёх
  производственных этапов и выдачи;
- проверены lint, форматирование, быстрые и PostgreSQL-интеграционные тесты;
- production-сборка client/server проходит.

## Ограничение

Касса и пользовательский интерфейс оплат в этой итерации не расширялись по
решению заказчика.
