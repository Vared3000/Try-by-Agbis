# Отчёт по итерации 17 — рабочая навигация и скорость интерфейса

## Реализовано

- настоящие URL для разделов приложения;
- прямая ссылка на карточку конкретного заказа;
- сохранение выбранного фильтра заказов в URL;
- корректная работа обновления страницы и кнопок Back/Forward;
- debounce поиска заказов, клиентов, номенклатуры и производственной очереди;
- закреплённая панель основных действий заказа;
- двухпанельное рабочее место производства;
- закреплённая карточка выбранного изделия;
- ограниченная по высоте прокручиваемая очередь;
- автоматический возврат фокуса в поле сканера;
- русское название статуса в производственной карточке;
- технический код бирки скрыт под раскрываемым блоком.

## UX-эффект

- приёмщик не теряет карточку заказа после обновления страницы;
- ссылку на заказ можно открыть в новой вкладке или передать коллеге;
- основные действия остаются видимыми в длинном заказе;
- технолог видит очередь и выбранное изделие одновременно;
- поиск не отправляет запрос после каждого нажатия клавиши.

## Проверка

- добавлен компонентный тест прямой ссылки на заказ и перехода между разделами;
- все клиентские и серверные тесты проходят;
- lint, форматирование и production-сборка проходят.
