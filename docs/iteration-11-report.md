# Отчёт по итерации 11 — рабочее место приёмки

## Реализовано

- самостоятельная сущность позиции номенклатуры;
- единицы измерения: штука, квадратный метр, погонный метр и килограмм;
- серверные правила расчёта количества, площади и стоимости;
- создание и редактирование номенклатуры через модальное окно;
- предварительный расчёт площади и стоимости в форме номенклатуры;
- ввод фактических размеров конкретного изделия в заказе;
- фиксация цены позиции в заказе;
- отдельное окно поиска клиента по телефону или ФИО;
- выбор существующего или создание нового клиента из окна приёмки;
- материалы, цвета, дефекты и загрязнения позиции;
- удаление ошибочной позиции из черновика;
- поиск и фильтрация списка заказов;
- автоматическое назначение стандартного производственного маршрута;
- запуск и завершение производственных этапов после сканирования бирки.

## Проверка

- расчёт `2 × 3 м × 590 ₽/м² = 3 540 ₽` проверен интеграционным тестом PostgreSQL;
- заказ с позициями номенклатуры принимается без фиктивной услуги;
- цена и рассчитанные параметры сохраняются снимком в заказе;
- быстрые, компонентные и интеграционные тесты проходят;
- production-сборка client/server проходит.

## Вне текущего расширения

Касса и пользовательский интерфейс оплат оставлены без расширения по решению
заказчика.
