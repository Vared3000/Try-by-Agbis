## Каталог разрешений MVP

- клиенты: `clients.view`, `clients.create`, `clients.update`;
- заказы: `orders.view`, `orders.create`, `orders.update`,
  `orders.cancel`, `orders.issue`, `orders.issue_with_debt`;
- деньги: `payments.view`, `payments.create`, `payments.refund`,
  `cash_shifts.manage`;
- скидки: `discounts.manual`;
- производство: `production.view`, `production.transition`,
  `production.assign`, `production.quality_control`;
- справочники: `catalog.view`, `catalog.manage`, `price_lists.manage`;
- файлы: `files.view`, `files.upload`;
- отчёты: `reports.operational`, `reports.financial`;
- администрирование: `users.manage`, `roles.manage`, `settings.manage`;
- контроль: `audit.view`.

## Обязательные ограничения

- frontend использует permissions только для интерфейса;
- backend повторно авторизует каждое действие;
- запрос ограничивается организацией и разрешёнными филиалами;
- индивидуальный запрет имеет приоритет над разрешением роли;
- пользователь не может расширить доступ передачей `organizationId` или
  `branchId`;
- финансовые отчёты и возвраты недоступны по одному лишь праву просмотра заказа;
- superadmin не получает неявный доступ к tenant-данным.
