# Отчёт по итерации 16 — печатные документы

## Реализовано

- тестовый шаблон клиентской квитанции A4;
- отдельные редактируемые блоки реквизитов и условий;
- таблица изделий и услуг;
- суммы, оплата и остаток;
- комплект бирок для всех позиций заказа;
- отдельная страница `55 × 55 мм` для каждой бирки;
- QR, Code 128, номер заказа, номер и название позиции;
- кнопки печати квитанции и всех бирок в карточке заказа;
- сохранена отдельная печать конкретной бирки;
- предварительное открытие вкладки устраняет блокировку документа браузером.

## Расширяемость

HTTP-маршруты отделены от функций разметки. Реквизиты, логотип, юридические
условия и дополнительные поля можно менять в печатном слое без изменения
интерфейса заказа.

## Проверка

- модульные тесты проверяют A4, экранирование пользовательских данных и точный
  размер бирки;
- PostgreSQL-интеграционный тест проверяет квитанцию и комплект бирок реального
  заказа;
- существующая проверка декодирует QR с PNG и подтверждает отсутствие
  персональных данных.
