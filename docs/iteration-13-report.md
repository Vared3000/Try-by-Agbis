# Отчёт по итерации 13 — очередь производства

## Реализовано

- общая очередь изделий, находящихся в производстве;
- поиск по номеру заказа, клиенту, телефону, названию изделия и коду бирки;
- фильтрация по рабочему статусу;
- отображение клиента, заказа, текущего статуса и срока готовности;
- визуальное выделение просроченного срока;
- открытие карточки изделия из очереди без ручного ввода кода;
- автоматическое обновление очереди после производственного перехода;
- расширенная карточка сканирования с номенклатурой и клиентом.

## Проверка

- интеграционный тест проверяет поиск изделия в очереди;
- фильтр текущего производственного статуса проверяется после запуска этапа;
- филиальная и организационная изоляция применяются на сервере;
- внутренние статусы черновика, выдачи и отмены не попадают в рабочую очередь.

## Ограничение

Очередь возвращает не более 200 изделий за один запрос. Сервер уже сообщает
общее количество, поэтому постраничную навигацию можно добавить без изменения
формата ответа.
