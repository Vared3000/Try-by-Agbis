# Отчёт по итерации 14 — управление прайс-листами

## Реализовано

- дата завершения действия прайс-листа;
- русские подписи статусов;
- активация черновика;
- отключение активного прайс-листа;
- возврат неактивного прайса в черновики;
- редактирование существующей цены;
- удаление ошибочной строки;
- общая цена услуги без привязки к конкретному типу изделия;
- запрет изменения строк отключённого прайс-листа.

## Целостность расчётов

Редактирование прайса не меняет стоимость уже добавленной услуги. При
добавлении услуги в заказ сервер сохраняет снимок названия, цены, количества и
итоговой стоимости. Поэтому последующие изменения справочника влияют только на
новые позиции.

## Проверка

- PostgreSQL-интеграционный тест проверяет создание, изменение и удаление цены;
- компонентный тест проверяет редактирование цены пользователем;
- формат денежных значений передаётся в API в копейках без вычислений с
  плавающей точкой на сервере.
